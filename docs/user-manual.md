# 標籤管理系統 使用說明書

> 給店內員工看的操作手冊。不需要懂程式。

---

## 1. 開啟系統

1. 雙擊桌面上的 **`start.bat`**（或「標籤管理」捷徑）。
2. 會跳出一個黑色視窗，寫著「請勿關閉此視窗」——**不要關掉它**，關掉系統就停了（可以最小化）。
3. 打開瀏覽器（Chrome 或 Edge），網址輸入：**http://localhost:8080**

## 2. 畫面說明

```
┌──────────────────────────────────────────────┐
│ 🏷 標籤管理              今天 11/13   [☀️ ◯ ]  │ ← 日期、日夜切換
│ ┌──────────┬──────────┬──────────┐           │
│ │ 5 安全   │ 2 即將到期│ 1 即將／已過期│      │ ← 三色統計
│ └──────────┴──────────┴──────────┘           │
├──────────────────────────────────────────────┤
│ (1) (2) (+)                                   │ ← 分頁
│ ┌ 第 1 層 ────────────────────────── ☰ ┐     │ ← 層架
│ │ [火腿卡片] [BBQ醬卡片] [+ 新增品項]  │     │
│ └──────────────────────────────────────┘     │
└──────────────────────────────────────────────┘
```

### 品項卡片顏色

| 顏色 | 意思 | 要做什麼 |
|---|---|---|
| 🟢 綠色「還有 N 天」 | 安全 | 不用動 |
| 🟡 黃色「剩 1 天」 | 明天到期 | 準備換標或備料 |
| 🔴 紅色「今天丟棄」／「已過期」 | 到期 | 今天處理：丟棄或換標 |

### 日期怎麼算

- **開封日** = 解凍日 + 解凍天數（貼紙上的「解」）
- **丟棄日** = 開封日 + 保存天數（貼紙上的「放」）
- 例：火腿 解1 放2，10/28 解凍 → 10/29 開封 → 10/31 丟棄

## 3. 日常操作

### 3.1 新增品項
1. 在要放的層架上，點最右邊的 **「+ 新增品項」**。
2. 填寫：品名（最多 30 字）、解凍日期（預設今天）、解凍天數（0–30）、保存天數（0–365）。天數可以按 **−／+** 調整。
3. 按右上角 **「新增」**。

### 3.2 換標
1. 在品項卡片上按藍色 **「換標」**。
2. 確認視窗按 **「換標」** → 解凍日自動變成今天，開封日、丟棄日重新計算。
3. 照卡片上的新日期寫標籤貼上即可。

### 3.3 刪除品項
點卡片右上角的 **✕** → 確認「刪除」。

### 3.4 移動品項
- **電腦**：用滑鼠按住卡片拖到想放的位置（同層調順序或拖到別層），虛線框就是放下後的位置。
- **注意**：本系統只能在放置系統的這台電腦上操作，手機與平板無法開啟或修改資料。

### 3.5 層架
| 想做的事 | 怎麼做 |
|---|---|
| 改名 | 直接點層架名稱修改，按 Enter 完成 |
| 新增層架 | 頁面最下方「新增層架」 |
| 調整順序 | 按住右側 ☰ 上下拖 |
| 刪除層架 | 點右側 ☰（層架必須是空的，有品項會提示先清空） |

### 3.6 分頁
- 點分頁標籤（1、2…）切換頁面；點 **+** 新增分頁。
- 在目前分頁上再點一次 → 可以改名或刪除（分頁內要沒有層架才能刪，會確認兩次）。
- 新增的層架會放在目前分頁。
- 分頁設定存在這台電腦的瀏覽器裡，換電腦或清除瀏覽器資料會回到預設分頁（品項資料不受影響）。

### 3.7 白天／夜間模式
- 右上角的切換開關：**點一下**，或**按住圓形把手左右滑**。
- ☀️ 把手在左 = 白天模式（淺色，有太陽和雲）
- 🌙 把手在右 = 夜間模式（深色，有月亮和星星）
- **自動切換**：每天 **16:00 至隔天 04:00** 為夜間模式，其餘時間為白天模式，到時間會自動換。
- **手動切換**：可以隨時點一下改成另一種模式；手動選的會保留到下一個時段（04:00 或 16:00），到點就自動依時段切換。

## 4. 常見問題

| 狀況 | 處理方式 |
|---|---|
| 網頁打不開 | 確認黑色視窗還開著；沒有就重新雙擊 `start.bat` |
| 日期沒有跳到今天 | 系統每 60 秒自動更新；也可以按 F5 重新整理 |
| 出現紅色提示訊息 | 照訊息內容處理（例如層架還有品項不能刪）；看不懂就按 F5 再試一次 |
| 品項不見了 | 先確認是不是在別的分頁；再不行請聯絡管理者，不要重裝程式 |
| 黑色視窗出現一堆英文 | 正常，那是系統紀錄，不用理它 |

## 5. 關閉系統

下班不需要關。若要關：在黑色視窗按 `Ctrl + C`，或直接關掉黑色視窗。

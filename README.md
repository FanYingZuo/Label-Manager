# Label Manager（標籤管理系統）

解決店內食材換標來回奔波、容易漏看或算錯日期的食材標籤追蹤管理系統。

---

## 為什麼做這個

店裡的食材各有不同的保存期限，品項也常常上下架，所以每個品項到期時都要換一次標籤。

標籤機放在辦公室，離食品存放區很遠。目前換標的流程是：

1. 到冷藏區看標籤，確認哪些品項要換。
2. 回到辦公室寫標籤。
3. 再走回冷藏區，把舊標籤換掉。

每換一批就要來回跑好幾趟，既花時間，也容易漏看或算錯日期。

這個系統要解決的，就是這些來回跑的時間。員工在電腦前就能看到今天要換標的品項，一目了然掌握所有層架食材狀態，一次完成換標。

---

## 主要功能

- 📊 **頂部三色狀態統計**：即時顯示「安全（綠色）」、「即將到期（黃色）」、「今天丟棄／已過期（紅色）」品項數量。
- 🧊 **層架視覺化管理**：預設 6 層，支援自訂層架名稱（留空自動還原為「第 N 層」）、新增層架與防護移除最後一層（有品項不可移除）。
- 📝 **品項快速新增**：每層右側提供「+」新增方塊，輸入品名、解凍天數與保存天數即可加入。
- 🔄 **一鍵換標**：點擊品項上的「換標」按鈕，解凍日自動更新為今日，並精確重新計算開封日與丟棄日。
- 🔀 **拖曳排序與跨層移動**：支援 HTML5 拖曳，同層可調整順序，亦可直接拖曳跨層移動。
- 🛡️ **純領域模型驅動**：核心業務邏輯為純 Java 17 實作，並涵蓋 100% 業務案例單元測試與 API 整合測試。

## 技術棧

- **後端語言**：Java 17
- **應用框架**：Spring Boot 3.2.5 (Spring MVC, Spring Data JPA)
- **資料庫**：SQLite (內嵌輕量資料庫 `labelmanager.db`，開箱即用)
- **測試框架**：JUnit 5, MockMvc, AssertJ
- **前端技術**：原生 HTML5, CSS3, Vanilla JavaScript (HTML5 Drag & Drop API，無需安裝 Node.js 或 npm)
- **CI/CD**：GitHub Actions 自動化測試工作流

## 快速啟動

### 環境需求
- JDK 17 或以上
- Apache Maven 3.8+

### 啟動步驟

1. **複製專案並進入目錄**：
   ```bash
   cd Label-Manager
   ```

2. **執行測試**：
   ```bash
   mvn test
   ```

3. **啟動系統**：
   ```bash
   mvn spring-boot:run
   ```

4. **開啟瀏覽器**：
   瀏覽器訪問：[http://localhost:8080](http://localhost:8080)
   系統預設會自動載入 6 個層架與初始範例資料，即可立即體驗操作！

## 核心計算規則

- **開封日** = 解凍日 + 解凍天數
- **丟棄日** = 解凍日 + 解凍天數 + 保存天數
- **剩餘天數** = 丟棄日 − 今天

| 剩餘天數 | 狀態 | 顯示文字 | 標籤顏色 |
|---|---|---|---|
| $\ge 2$ | 安全 | 還有 N 天 | 綠色 |
| $1$ | 即將到期 | 剩 1 天 | 黃色 |
| $0$ | 今天丟棄 | 今天丟棄 | 紅色 |
| $< 0$ | 已過期 | 已過期 | 紅色 |
